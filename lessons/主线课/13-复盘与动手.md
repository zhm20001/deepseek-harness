# 13 — 复盘与动手：这套 harness 反复用的三板斧

> 本课是收官：回答"这套 harness 反复用什么手法守不变量"，把 12 课收进一张复盘表，再给你一条自己动手的路线。前面的课都是"看别人做"；这一课是"你来走一遍"。

## 逻辑层

### 一、第一板斧：扩展点，不改内核

**大白话**：想加任何行为，先找"有没有一个闸、一个域、一块接缝能站"，而不是改那台转着的机器。行为长在边上，核心保持不动。

**术语**：plugins not loop changes（改 agent-loop 必须同步改架构文档——说明那是大事）。

**例子（你见过的）**：三道闸上站满了插件（05/07 课）；事件三域承接一切观察与拦截（05 课）；换厂商、换沙箱、换分身 transport 都不动 loop（09/10/11 课）。

**推论**：判定法：一个新需求若找不到现成接缝，先怀疑自己没找够，再考虑新开一块接缝——开接缝是正经路，改内核是最后手段。

### 二、第二板斧：显式化，不藏默认

**大白话**：所有"默认怎么办"都必须是**看得见的一步**（一个明确的解析动作），而不是藏在函数深处的暗默认。谁的默认，谁负责摆上台面。

**术语**：explicit > implicit；标志性形态是"请求 → 规格"两步（先解析成完整规格，再执行）；配套一条：部署间可变的数值必须做成**配置字段**，写死在代码里的常数不算可配置。

**例子（你见过的）**：bash 的请求先解析成规格再执行（10 课，全仓模板）；验票据根上写明哪些字段是厂商代定的（09 课）；沙箱策略按每次调用携带（10 课）；SDK 只能点菜不能进厨房（12 课）。

**推论**：读代码时看到"两步走"，第二步之前的东西都是全须全尾的规格——没有半个隐藏开关。

### 三、第三板斧：当场拒绝，不留悬案

**大白话**：不对的东西，在**它诞生的那一步**就被拒收——宁可当场停机，也绝不带病往前走、绝不悄悄跳过。

**术语**：fail loud（配置坏了在装载时报，引用断了在最早能判断时报）；配上 04 课的追加式档案，连"出事之后"也不留悬案——半截回合有收尾记录，失败尝试有只留档不上镜的记录。

**例子（你见过的）**：档案追加当场校验，坏数据死在登记处（04 课）；不认识的日志词整卷拒读（04 课）；找不到笼子拒绝裸奔（10 课）；工具结果快照坏数据当场抛（07 课）。

**推论**：这套系统里"安静"是坏事，"吵闹的失败"是好事——出错的信息越早、越响，账目越干净。

### 四、复盘表：五条不变量与它们的老家

| 不变量（探针） | 老家 | 被消费的地方 |
|---|---|---|
| ① 注册是 effect，卸载必须回卷 | 01 课账本 | 03 课 Scope、04 课 session、12 课 bundle |
| ② 事件是扩展点，选域先于选包 | 05 课三域 | 07 课工具闸、11 课工作流播报 |
| ③ 模型可见 ⟺ 可从日志重建 | 04 课档案室 | 06 课请求现算、08 课 inject 走窄门、12 课界面渲染 |
| ④ 换 provider 换整个世界 | 03 课接缝 | 09 课 adapter、10 课远程换装、11 课分身 transport |
| ⑤ 强制发生在做决定的操作里 | 07 课闸门 | 10 课 argv 包装、10 课意图闸 |

**推论**：读任何没学过的包，拿这张表当探针：它 provide 什么、站哪道闸、什么必须入档、换掉它谁会塌、它的强制发生在哪一步。

### 五、动手：照食谱加一条最小接缝

按 `docs/cookbook/adding-a-package.md` 走一遍全流程：**开 Definition 包**（一个抽象 Service，契约写全）→ **开 Provider 包**（一种实现，注册即 effect）→ **开一个工具包**（纯 Consumer，inject 三件套，UI 展示提前设计）→ **配一个 bundle 改单**让 profile 能点亮它（12 课层序）→ 跑 `pnpm run test:coverage` 与 `pnpm run doc-sync` 全绿（coverage 是逐文件 100% 的硬门槛，新包从第一行就要带着测试活）。做完这条，你就把五条不变量亲手各摸了一遍。

## 记住什么 / 不用记什么

**记（4 个）**：plugins not loop changes；explicit > implicit（请求→规格两步）；fail loud（当场拒绝 + 追加式档案不留悬案）；branded ids（跨边界名字加防伪戳，从不裸用字符串）。

**不用记**（卡住回溯）：三条板斧的具体出处行号、coverage 门槛的数字、Agent Notes 四篇的标题——板斧认得出来就行，出处回本表查。
