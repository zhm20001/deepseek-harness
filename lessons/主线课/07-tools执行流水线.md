# 07 — Tools 执行流水线：模型想动手，经过哪几道闸

> 本课回答两个问题：模型发出的每一次工具调用，从"它说想调"到"结果回到它眼前"经过哪几道闸？为什么"拒绝"必须发生在闸上？接缝：06 课一步里的"工具执行那一段"（loop 交给 `ctx.tools`）就是本课正主；01 课那个"审批 waterfall"的例子也在这里兑现——主线不变量⑤（强制发生在做决定的操作里）的主场。

## 逻辑层

### 一、先记账，再动手

**大白话**：模型说"我要调 bash"——这句话先**原样记进档案室**，然后才开始走闸门，界面上同时挂出一张"待执行"的卡片。像医院先挂号登记，医生才能处置。

**术语**：`tool/call` 事件在执行**前**入档，连参数都是模型的原话（没解析过的 JSON 字符串）。

**例子**：正因为参数已经入档、已经挂在界面上，开跑前的闸门**不许改参数**——改了就是档案一套、实际一套。

**推论**：不变量③管住了闸门的手：先记账再动手，动手的人就不能改账。想影响调用，只能放行或拦下，不能偷改。

### 二、三道闸：开跑前 → 执行中 → 跑完后

**大白话**：一次工具调用像过安检。**开跑前**的闸：门卫看一眼——放行、拦下、拿不准就问人。**执行中**的闸：一圈"包场"的护栏，管超时、重试、计时，工具本体在护栏里干活。**跑完后**的闸：验收员——照单收下、整单退货，或贴一张便签给下一轮的模型。

**术语**：`tools/pre-execute`（waterfall，决定只有四种：放行 / 拦下 / 当成取消 / 问人）；一排**单调门卫**（只回答"拦"或"不表态"，永远说不出"放行"）；`tools/execute`（waterfall 环绕，超时重试住这里）；工具本体；`tools/post-execute`（收下或把纠正意见变成错误结果）。

**例子**：提醒"你刚才调过同一个命令"的插件守在跑完后的闸上；超时策略包在执行中的护栏外面；沙箱的"绝不许碰网"是一名单调门卫。

**推论**：三段各有专责、互不越位。钩子想横跨所有工具家族，站到闸上就行——不用认识每件工具，工具也不用认识它。

### 三、审批与保安：拒绝必须发生在闸上

**大白话**：门卫拿不准时可以"问人"（ask）——问题通过**审批招牌**递给真正能拍板的人：终端弹窗、网页卡片、SDK 回调，各答各的；没人能答、或答了"不行"，一律按"拦下"处理。旁边还站着一排保安（guards）：他们只会说"拦"或"不表态"，**永远不会说放行**——所以不管谁排在前面，都翻不了已经拦下的案。

**术语**：`ctx.approval` 审批接缝（"同意一次"才算数，每次问和答都记进会话日志）；单调门卫（返回拦下理由，或不出声）。

**例子**：部署时指定"策略永不询问"，审批招牌就自动代答"不行"——无人值守的模式照样安全。

**推论**：不变量⑤的原话在这里落地：把工具从名单上划掉（schema 省略）只是"没报名"，不是"拦截"——只要还存在任何旁门能调到它（比如子代理、代码模式的内部转发），就必须靠闸门拦住。而代码模式的内部转发**同样过这三道闸**，旁门不豁免。

### 四、跑完后：结果先冻结，再入档

**大白话**：工具跑完，结果先拍一张**快照**冻住，再挂到界面上、记进档案——和 04 课的追加校验一个脾气：坏数据死在登记处，不能死在落盘时。

**术语**：结果必须无损 JSON、深冻结；`tools/result` 通知看到的是冻结后的最终结论；每笔调用在档案里只有一条 `tool/result`。

**例子**：文件工具会把"结果发生时的上下文差异"挂在结果的 meta 里随档走，回放时界面卡片原样复原。

**推论**：界面卡片和模型看到的结论出自同一份冻结快照——界面不会骗模型，模型也不会骗界面。

### 五、三问检验：审批招牌

拿三问读 `dsh-user-approval`：**provide** 什么——`ctx.approval`（先按会话策略裁一道，再把问题递给能拍板的人）；**inject** 什么——`['systemPrompt']`（把"现在会不会问你"写进系统提示，让模型心里有数）；**on** 什么——无。它是 `approval/request`（waterfall）的**发声者**，把问题沿 03 课的作用域话筒递给这个 agent 的前端。

## 记住什么 / 不用记什么

**记（4 个）**：先记账再动手（tool/call 先入档、参数不许闸门改）；三道闸（pre-execute → execute 包场 → post-execute）；审批与保安（ask 问人、答不了算拦；保安只会拦不会放）；拒绝必须在闸上（schema 省略不算强制，旁门同样过闸）。

**不用记**（卡住回溯）：`ToolRuntime` / `PreToolDecision` / `ToolGuard` 这些类型名、调度器"独占成栅栏、可并行进池子"的细节、PTC 的 run_code 保留名、结果快照的实现函数——全部是四条规则的具体实现。
