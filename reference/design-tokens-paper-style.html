纸感信纸风 Design Tokens

从 palette / diary / lessons 三个项目中提取的统一风格。值的唯一权威定义在 assets/tokens-paper.css，本页是它的可视化文档。

1. 色板

--paper #fffff8
--desk #f6f4eb
--card-bg #fffdf4
--ink #1a1a1a
--ink-body #3a3a35
--ink-muted #6b6a63
--accent #b0413e
--rule #d8d4c8
--chip-bg #f4f2ea
--ok #2e6e3e
--bad #a03030

2026-08 新增：--desk（纸下桌面色，diary 首创）、状态色 --ok / --bad（lessons 血统）。加色流程：先在此文档试挂 → 浏览器目检 → 固化进 tokens-paper.css。

2. 字体

标题与正文用衬线：宋体 × Palatino（--font-serif）

辅助文字（标签、代码、meta）用无衬线/等宽：SF Mono / ui-monospace，与 lessons 的 course.css 一致。

3. 组件形态

卡片：纸底 + 1px 米色边框 + 10px 圆角；hover 时边框转近黑并上浮投影。

主按钮　朱红底白字，衬线字体，hover 加深为 #963633。

状态色用法：✓ 成功（--ok）　✗ 失败（--bad），配 --ok-soft / --bad-soft 弱化底色（见 lessons 测验组件）。

边框层级：1px solid #d8d4c8（弱）→ 2px solid #1a1a1a（强，如 board 外框）。

4. 新项目接入方式

  1. 引入权威源 assets/tokens-paper.css（<link>、构建 import，或零构建项目内联其 :root 块并注明来源）；
  2. 项目内部只做一层前缀别名，如 --pb-paper: var(--paper)，业务样式一律消费前缀变量；
  3. 不直接写十六进制色值、不直接写字体栈——出现第二次即是坏味道；
  4. 多主题（如 palette 的 fresh/glass）：用 data-theme 属性覆写同一批 token，而非两套类名。

5. 形态对照（2026-08-31 开源定稿：vendor 副本制）

项目消费方式落点
权威源—（唯一裸值所在地）deepseek-harness/assets/tokens-paper.css
lessonscourse.css 顶部 @import + 本地别名（同仓库，无需副本）deepseek-harness/assets/course.css
palettevendor 副本 + index.tsx 副作用导入 + 别名层dsh-plugin-palette-board/src/client/tokens-paper.css
diaryvendor 副本 + 运行时 readFileSync 内联 + 别名层dsh-diary/assets/tokens-paper.css + src/paths.ts

原则（开源发布定稿版）：真相只有一份（权威文件）；插件仓库内的副本是带 sha256 生成头的衍生品，随仓库提交——因为仓库内容即分发物。改风格 = 改权威 → node assets/sync-tokens.mjs → 重建；push 前必须 --check。曾用 symlink 活指针方案，因插件开源而退役：公开仓库里的符号链接指不进别人的机器。
