Web UI 呈现方式术语表

Lesson 0008的压缩版。忘了才翻,不背。每个术语附「技术指纹」(DOM/CSS/ARIA 线索)与「你机器上的标本」。

先记一条主轴,再看表

所有 surface 的第一分叉只有一个问题:新内容和宿主页面是不是同一个 document?

  • 同 document(浮层系) — 内容叠在原页面上方或嵌进原页面。共享 JS 上下文、状态、路由,通信是函数调用。overlay / modal / popover / drawer / tab 都在这边。
  • 新 browsing context — 浏览器另开一个独立页面(新标签页 / 新窗口 / iframe),与原页面互不知晓,只能靠 HTTP / postMessage 通信。

第二分叉(浮层系内部):打断不打断。打断底层交互的叫 modal(模态);不打断的叫 modeless / popover / drawer 等。第三档是生命周期:临时开关(modal)、常驻切换(tab)、并行同开(独立页面)。

家族全景

同 document · 浮层系

术语一句话技术指纹何时用
overlay
覆盖层		 盖在页面内容之上的一层,统称。本身不规定交互。 position:fixed; inset:0 + 高 z-index 任何"盖上去"的形态的基底;full-screen overlay 用于临时全屏任务视图。
modal dialog
模态对话框		 打断式:背景变 inert(不可交互),焦点被圈住,必须处理完才能走。 role="dialog" aria-modal="true" + 焦点陷阱 + backdrop(遮罩/scrim)。原生 <dialog>.showModal() 必须让用户停下注意的事(确认危险操作、填一段完整输入)。克制使用——打断是税。
command palette
命令面板		 modal 的子类:搜索驱动的快速命令/跳转面板。 modal 指纹 + 搜索框自动聚焦 + 键盘导航(⌘K) 功能多而深、不想做导航结构时的统一入口。
modeless dialog
非模态对话框		 对话框但不打断:用户可以继续操作背景内容(经典如"查找替换")。 <dialog>.show()(非 showModal) 工具型小窗,开着的同时要反复参考底下的内容。
drawer / side panel
抽屉/侧面板		 从屏幕边缘滑入的面板,可模态可不模态。移动端从底部来的叫 bottom sheet。 停靠一侧 + transform 滑入动画 中等体量的辅助信息/设置,想半屏对照着看。
popover
弹出层		 锚定在触发元素旁的小浮层,点外部即关。 popover 属性 / CSS Anchor Positioning;popovertarget 轻量选择、补充说明,与某个按钮/字段强相关。
tooltip hover/聚焦时出现的一两句提示,不可交互。 CSS :hover 或 popover 变体 名词解释、快捷键提示。
toast / snackbar 自动消失的通知条,不打断。 role="status" / aria-live "已保存""已复制"这类结果反馈。
lightbox 图片/媒体的居中放大查看层。 modal 指纹 + 点击背景关闭 预览图片、 diff 大图。

同 document · 非浮层系(原地扩展/切换)

术语一句话技术指纹何时用
tab panel
标签页面板		 同一位置的一组平行视图,点标签切换,常驻。 role="tablist" / tab / tabpanel + 方向键导航(APG Tabs Pattern) 内容归属于某个已有容器(如"这个 session 的另一种视角")。
inline disclosure
就地展开		 不浮起,原地展开/收起一段内容(accordion 折叠组)。 <details>/<summary> 渐进披露详情,保持页面结构不跳。
route view(SPA)
路由视图		 单页应用里路由切换主内容区,整个 document 不重载。 history API / 前端路由(React Router 等),URL 可分享 应用主页面间的导航,需要可收藏/可前进后退的 URL。

新 browsing context

术语一句话技术指纹何时用
standalone page in new tab
新标签页独立页		 一个完整独立 URL 的页面,从入口链接在新标签页打开。 <a target="_blank" rel="noopener"> 指向独立路由 体量大、生命周期独立、要与主应用并行使用(一边聊一边写)。
popup window
弹窗(狭义)		 window.open() 开的独立小窗口。 JS 调用返回 window 引用,可跨窗口通信 OAuth 登录回调等需要独立窗口的场景;日常 UI 少用(易被拦截)。
iframe embed 页面内嵌另一个 browsing context 的框。 <iframe> 嵌入第三方页面/隔离样式脚本;沙箱安全边界。

四个高频混淆对

  1. overlay vs modal:overlay 是实现词(一层盖上去的视觉层),modal 是行为词(打断 + 圈焦点)。一个 modal 视觉上 = backdrop(遮罩) + dialog surface;判断是不是 modal 永远看行为,不看 z-index 高低。
  2. dialog vs modal:dialog 是容器概念;modal 形容"阻断模式"。所以存在 modeless dialog。原生 <dialog> 双证件:show() = modeless,showModal() = modal。
  3. popup 的语义漂移:历史上 popup = window.open 的浏览器弹窗(广告时代);如今口语里常指页面内 popover。正式语境写 popover 或 modal,别写 popup。
  4. 两种 tab:页面内 tab(tablist/tabpanel,ARIA Tabs Pattern)≠ browser tab(浏览器标签页)。dsh 的 conversation.view 是前者;diary 的 target="_blank" 开的是后者——中文都叫"标签页",层级完全不同。
